# CmdQ Guard

*macOS menu-bar utility that requires holding ⌘Q to quit — prevents accidental app quits, with per-app protection lists.*

Утилита с окном настроек и значком в строке меню macOS. Короткое ⌘Q блокируется; удерживание ⌘Q в течение заданного времени отправляет обычный запрос на завершение текущего приложения. Галочка включает или выключает защиту, ползунок задаёт задержку от 0,5 до 3 секунд; настройки сохраняются между запусками.

Защиту можно ограничить списком приложений: переключатель «Все приложения / Только выбранные / Все, кроме выбранных» и список, куда программы добавляются из запущенных или через диалог выбора файла. Если список пуст, защита действует везде.

## Сборка

В Терминале выполните `./build.sh`. Получится `CmdQ Guard 4.app` рядом с исходниками.

При запуске открывается окно с пошаговой подсказкой и статусом перехвата. Также в строке меню есть значок клавиатуры и ⌘Q с теми же переключателем и ползунком. Закрытие окна скрывает его, но оставляет приложение работающим: открыть его снова можно нажатием значка приложения в Dock или через менюбар. Для работы перехвата macOS просит вручную добавить CmdQ Guard 4 в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. После включения переключателя вернитесь в приложение и нажмите **Проверить разрешение**. Сборка подписывается локальным сертификатом CmdQ Guard Local из связки ключей, чтобы macOS распознавала ту же программу при следующих пересборках.

Приложение использует системный обработчик событий macOS. Если игра или другой софт эксклюзивно захватывает клавиатуру, ОС может не передать сочетание приложению.
